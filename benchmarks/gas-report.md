# SPHINCS- C13 Gas Report — Phase 1

Date: 2026-08-24
Environment: Foundry (solc 0.8.28, optimizer 200 runs, via-ir), Anvil default settings (post-Shanghai).

## What was measured

`SphincsMinusVerifier.verify(bytes32 pkSeed, bytes32 pkRoot, bytes32 message, bytes sig)`
on three static vectors generated by the reference Rust signer
(`nconsigny/SPHINCs-`, signer-c13). Identical inputs were run against the
reference Yul-optimized contract (`SPHINCs-C13Asm.sol`) for comparison.

## Results

| Verifier | Style | Gas (verify only) | Notes |
|---|---|---|---|
| `SPHINCs-C13Asm.sol` (reference) | single inline-assembly block | **100,251** | deterministic across all 3 vectors |
| `SphincsMinusVerifier.sol` (ours, v0) | readable Solidity, no asm hot loops | **603,296 – 606,194** | ~6× reference |

### Reconciling with the published number

The June 2026 ethresear.ch post reports **~127,000 gas** for C13. Our reference
measurement is lower because it excludes transaction-level calldata cost:
a 3,704-byte signature plus ABI overhead (~3.7 KB × 16 gas/nonzero-byte ≈ 59K)
brings the end-to-end figure into the published range under EIP-7623-style
floor pricing. This is consistent, independently reproduced evidence that the
paper's numbers are real on vanilla Anvil opcode pricing.

## Interpretation

- The optimized assembly path is the gas ceiling-breaker: the reference gets
  ~6× over naive-but-correct Solidity by eliminating memory allocation,
  using scratch-slot reuse and branchless Merkle swaps.
- Our v0 exists as the auditability baseline: every step maps 1:1 to the FIPS
  205 algorithm description. Next optimization pass (Phase 1b) should port the
  hot loops (WOTS chains, Merkle walks, PK compressions) to assembly while
  keeping function boundaries and this file's structure as documentation.

## Correctness gate (all passing)

- 3 reference-signer vectors accepted.
- 256-run fuzz: flipping any single signature bit always rejects.
- Wrong message / swapped key material / non-canonical keys / bad length all
  rejected or reverted as designed.
